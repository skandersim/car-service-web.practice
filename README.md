# 🔧 Автосервис «АвтоПрактик»

> 🚧 **Проект в разработке (WIP).** Учебный пет-проект для практики фронтенд-разработки на чистом **HTML, CSS и JavaScript** — без фреймворков, сторонних библиотек и сборщиков.

Одностраничный сайт современного автосервиса с перечнем услуг, витриной автотоваров, графиком работы и онлайн-записью на обслуживание.

---

## ✨ Что уже реализовано

- **🌗 Палитра тёмной и светлой тем** — цветовая система на CSS-переменных (`data-theme`) с фирменным красным акцентом (`#dc2626`) и шрифтом `Inter`.
- **⚙️ Живая анимация поршня** — кастомная SVG-иллюстрация двигателя на главном экране с покадровым движением поршня и коленвала через `requestAnimationFrame`, `Math.sin` и `Math.cos`.
- **🧭 Шапка и Hero-экран** — фиксированная навигация с SVG-логотипом, индикатором работы сервиса и кнопками целевых действий.
- **🛡️ Секция «О нас»** — адаптивная Grid-сетка карточек преимуществ с векторными иконками и плавными hover-эффектами.
- **🧱 Каркас остальных разделов** — подготовлена семантическая разметка под блоки «Услуги», «Магазин», «Часы работы», «Отзывы», «Контакты» и подвал.

---

## 🚧 В планах доделать

- **🎨 Доверстать секции** — оформить карточки услуг, контакты, подвал и мобильный адаптив с бургер-меню.
- **🛒 Оживить интерактивные блоки** — добавить массив данных и рендер товаров магазина, отзывов клиентов и живого расчёта часов работы.
- **📝 Форма записи и фишки UI** — подключить модальное окно онлайн-записи, переключение темы, копирование адреса и плавное появление секций при скролле.

## 🛠️ Стек и отработанные навыки

| Технология | Что практикуется в проекте |
| :--- | :--- |
| **HTML5** | Семантическая разметка страницы, работа со встроенной SVG-графикой (логотип, иконки, механизм поршня) |
| **CSS3** | CSS-переменные для темизации, Flexbox и Grid, плавные переходы и микроанимации карточек |
| **Vanilla JS (ES6+)** | Работа с DOM, процедурная анимация SVG-элементов на `requestAnimationFrame` и тригонометрии |

Проект статический и не требует установки зависимостей:

1. Склонируйте репозиторий:
